# Security Policy

## Supported Versions

Security fixes are prioritized for the latest main branch and current production deployment.

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Report privately via:

- Email: `memoryostm@gmail.com`

Include:

- vulnerability description
- impact assessment
- reproduction steps or proof of concept
- affected endpoints/components

## Response Expectations

- Initial acknowledgment: within 72 hours
- Triage and severity assessment: as soon as possible
- Fix timeline: based on severity and exploitability

We appreciate responsible disclosure and will credit reporters when appropriate.
