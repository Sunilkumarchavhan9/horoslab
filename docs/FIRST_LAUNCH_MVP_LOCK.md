# memoryosTM First Launch MVP Lock

Status: Locked for first launch
Owner: Founder + Engineering

## MVP Promise

The second agent should not repeat the first agent's mistake.

First launch must prove one tight inheritance loop, not the entire future platform.

```text
GitHub / Markdown docs / manual notes / agent chat paste
  -> SourceItem storage
  -> Memory Extraction Engine
  -> Company Brain
  -> MemoryIgnition
  -> Inheritance Contract
  -> Inheritance Package
  -> AgentRun + Agent Black Box
  -> Outcome Required
  -> Future Instruction
  -> Mistake Immunity
  -> Skill Installed
  -> Evaluation Replay Proof
```

## Hard Product Rules

No AgentRun is complete until outcome is captured.

Memory tells agents what is true.

Skills tell agents how to act.

Policy tells agents what is allowed.

Proof tells humans why to trust it.

Outcome tells the system what to learn.

Agent Black Box is a top-three product pillar for first launch. It must answer:

1. What did the agent do?
2. Why did it do it?
3. What data did it access?
4. Was it allowed?
5. What proof exists?

## Inheritance Contract

Inheritance Contract is the canonical object every agent receives before work starts.

It defines:

1. `task`
2. `memory`
3. `rules`
4. `risks`
5. `requiredTests`
6. `permissions`
7. `approvedSkills`
8. `blockedActions`
9. `proof`
10. `outcomeSchema`

Implementation rule:

```text
MemoryIgnition prepares the Inheritance Contract.
Inheritance Package delivers the Inheritance Contract.
AgentRun executes under the Inheritance Contract.
Agent Black Box proves what happened under the Inheritance Contract.
Outcome Capture teaches the next Inheritance Contract.
```

## Evaluation Replay Moves Earlier

A small Evaluation Replay must exist in the first launch path, not in a late-stage lab.

It should prove:

1. Baseline agent failed.
2. Inherited agent succeeded.
3. Mistake Repeat Rate dropped.
4. Tests Remembered increased.
5. Human Correction Rate dropped.

This is the investor/demo proof:

```text
Before memoryosTM: same mistake repeated.
After memoryosTM: mistake avoided with proof.
```

## First Launch Acceptance Test

The launch is ready when this demo works end-to-end with real backend data:

1. Import GitHub/docs/agent chat into SourceItems.
2. Extract approved Company Brain memories with proof.
3. Prepare a task in MemoryIgnition.
4. Generate an Inheritance Contract and Inheritance Package.
5. Start an AgentRun with Agent Black Box tracing.
6. Require and save an Outcome before the run can complete.
7. Create a Future Instruction, Mistake Immunity rule, and Skill candidate.
8. Install the approved skill into `.memoryos/`.
9. Replay the same task and show the inherited agent avoids the previous mistake.
