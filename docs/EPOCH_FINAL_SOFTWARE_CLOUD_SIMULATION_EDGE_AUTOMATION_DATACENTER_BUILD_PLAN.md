              TRAINING SIGNAL / TRAJECTORY CONTRACT [ADDITIVE]
              A versioned training record may contain:
              ├── Task and environment IDs / versions
              ├── Input observation and relevant context
              ├── Model / policy checkpoint that produced the output
              ├── Action, response, tool calls or state prediction
              ├── Expected outcome, ground-truth label or preference
              ├── Verifier output and reward components, where applicable
              ├── Success / failure / termination reason
              ├── Data source, license, consent and provenance
              └── Runtime / token / compute cost, where measured

              Use only fields appropriate to the training method.
              Keep training, validation and held-out evaluation splits
              independently versioned and protected from leakage.
