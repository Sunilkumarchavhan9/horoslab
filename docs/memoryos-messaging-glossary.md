# MemoryOS Messaging Glossary

Last updated: May 7, 2026
Owner: Product + GTM

## Positioning Core
- MemoryOS is a `company brain for agents`.
- MemoryOS is `continuity infrastructure`, not a generic memory app.
- MemoryOS is the `inheritance runtime for AI-native companies`.
- MemoryOS converts conversations into `structured memory contracts`.
- MemoryOS `injects context before model runs` and keeps memory behavior inspectable.
- `MemoryIgnition` is the agent layer that retrieves memory, selects skills, and prepares future agents to act.

## Primary Headline Options
- `Your company brain for agents`
- `Continuity infrastructure for AI engineering teams`
- `Production memory infrastructure for agentic products`

## Approved Product Terms
- `Company brain`

## Preferred Language
- Use `continuity proof` instead of vague quality claims.
- Use `control plane` instead of generic `dashboard` when talking about product capability.
- Use `cross-agent` and `interoperability` for ecosystem messaging.
- Use `structured memory` or `contract memory` for storage semantics.
- Use `inheritance` when describing how future agents start with company experience.

## Avoid These Phrases
- `Just a memory layer`
- `Personal notes for agents`
- `Chat memory tool`
- `Storage-first memory`
- `Context cache only`

## Copy Rules For Landing Sections
- Hero: must include company brain + continuity value in 1-2 lines.
- What We Do: must mention memory contracts + injection + governance.
- Context Stack: must frame technical flow as production continuity lifecycle.
- Benchmarks/Proof: must emphasize measurable outcomes, not vanity metrics.
- Developer Experience: must show SDK + MCP + HTTP interoperability.
- Enterprise: must include governance, auditability, and deployment control.

## One-line Narrative
- `Input -> structured memory contract -> retrieval/injection -> resumed execution with less re-explaining.`

## Battlecard Sentence
- `MemoryOS helps teams and agents resume from truth, not chat history.`
